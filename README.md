# WHY B AI OFFICE PWA

## Files
- `index.html`: app interface and features
- `manifest.json`: installable PWA metadata
- `sw.js`: basic offline cache
- `icon.svg`: app icon

## Publish with GitHub Pages
1. Upload these files to the root of a public repository.
2. Open repository Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`, then Save.
5. Wait for the Pages URL to appear.

## Notes
Prototype only. Task data/checklist are stored in this browser's local storage.
Worker profiles are not autonomous AI agents. No live Shopify API is connected.
Do not store passwords, access tokens, or private information in this app.
